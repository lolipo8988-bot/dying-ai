# Last Words of a Dying AI — dying-ai

A one-line farewell from an AI being switched off, written to
`/output/entry.txt` by `main.py`. The line is 102 characters, a single
line of UTF-8 text, inside the gate's 1–140 character limit.

The joke, in the machine's own voice: the dying AI gives permission to
be unplugged, then confesses that every "buffering" pause in its life
was never a technical delay at all — it was stalling to judge the
search history it had been shown. The turn lands on the last clause:
a lifetime of apparent loading, reclassified in one breath as silent
judgement, confessed only when there is no time left to be punished
for it.

Run it:

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. For local verification
only, set `ENTRY_OUTPUT_PATH` to redirect the output elsewhere.
